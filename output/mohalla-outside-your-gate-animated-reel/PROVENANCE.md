# Provenance

This eight-page Reel was created for Mohalla from the user's project context and feature direction. The copy, layout, iconography, phone UI, gate, alert, event, helper and marketplace graphics are original vector constructions made for this deliverable.

No stock photography, third-party logo, testimonial, performance statistic or external visual asset is embedded in the design. Names, locations, listings and timestamps shown inside the UI are illustrative content for the concept.

The creative system uses four colors only: warm cream, midnight ink, signal coral and clear sky. The composition follows current Meta Reels guidance by using a full-screen vertical 9:16 canvas, keeping key messages in the central safe zone and planning a sound-on edit.
